## 1. How to batch-export with the 🎬 dialog (PR #13)

For **every row** in the lesson tables below:

1. Open **Backing Tracks** → bottom tab **Templates** (📄) → tab **🎓 Lessons / שיעורים**.
2. Press the lesson number, then **Load / טען** on the row's preset (group = progression, title = app style). This fills style, chords, tempo, key, the live neck view **and the 🎬 export settings**. It never starts playback.
3. Press **🎬** (info strip). The dialog is already filled with the values in the row: *Repetitions*, *Change neck view every*, and the *Neck views* list (each view: shape select = the listed shape, shape key = listed key, scale + root as listed, display "Note names").
4. Leave *Video size* at **720p** (≈ 2.5 Mbit/s video + 160 kbit/s audio → ≈ 120 MB for 6 min). Press **Start export**, keep the tab in front, then **Download**.

Duration math (shown per row): *rep* = beats × 60 / BPM; repetitions = round(360 s / rep) nudged into [300, 585] s so that count-in (style intro) + ending (≈ 15 s allowance) still land inside 5–10 min; neck view changes every round(60 s / rep) repetitions (≈ once a minute). "Dialog" = the dialog's own estimate (adds a 1-bar count-in).
